🍰 SaiGanesh Bakery – UI/UX Website Redesign

UI/UX Design Task 1 – Future Interns (2026)

📌 Project Overview

This project is a UI/UX redesign of a local bakery website (SaiGanesh Bakery), created as part of UI/UX Design Task 1 by Future Interns.
The goal was to design a high-conversion, user-friendly website that clearly communicates services, builds trust, and drives users toward quick contact and ordering.

Local service websites often fail due to unclear messaging, weak CTAs, and poor mobile experience. This redesign solves those problems using real-world UX principles.
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
🎯 Objective

Clearly explain bakery offerings

Improve lead generation through strong CTAs

Build trust with visual hierarchy and layout

Ensure smooth experience across desktop and mobile

Design with a business outcome, not just visuals
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
👥 Target Audience

Local customers looking for custom cakes & desserts

Mobile-first users

Users who prefer fast contact via WhatsApp or phone
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
🖥️ Screens Designed

✔ Homepage – Desktop
✔ Homepage – Mobile
✔ Service Page – Desktop
✔ Contact Page – Desktop
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
✨ Key UX & UI Decisions

Strong hero section with clear value proposition

Primary WhatsApp CTA placed above the fold

Real product images to build trust

Card-based layouts for services and cakes

Minimal steps between interest → action

Consistent bakery-inspired color palette

Rounded corners, soft shadows, clean spacing

Mobile-first layout thinking
--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
🛠️ Tools Used

Figma – UI design & layout

UX principles: visual hierarchy, CTA optimization, responsive design
